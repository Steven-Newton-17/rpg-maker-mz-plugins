# Encounters for RPG Maker MZ

Version **1.1.0**. Rule-based random encounters, scripted battles, loot tables, and battle outcomes that depend on the story.
It does not replace RPG Maker's battle system; it decides *which* battle starts, *what drops*, and *what happens afterwards*.

## Spawn tables

A map with a table ignores its editor encounter list. The first rule whose conditions pass (and whose regions match the
player's tile) decides what can appear: weighted entries (a named battle or a plain troop), the step count, loot, and
gold/experience rates. If no rule passes there are no encounters, so monsters can leave when the story says so. Maps without
a table keep RPG Maker's behavior.

## Battles

A named battle has a troop, escape rules, loot, and ordered **outcome rules** (`result`: win, lose, escape, or any) with
conditions, effects, and a dialogue. A losing battle ends the game unless a matching lose rule says `defeat: "continue"`,
for example a lost duel that sends the party to the infirmary. Conditions are checked when the battle ends.

## Starting a battle

- The `battle` effect (from dialogue or a rule), the **Start Battle** plugin command, or `Encounters.start("id")`.
- The battle starts once the current event or dialogue is finished. A Thing that started it is `self` in the outcome effects.

## Data

`data/Encounters.json`: `{ "battles": { id: {...} }, "tables": { "<mapId>": {...} } }`, generated by the Game Manager.

## Requirements

ConditionSystem and DialogueSystem, loaded before this plugin. Interactions 2.0 is optional and refreshes Things after
an outcome.
