# Changelog

## 1.2.0 — 2026-10-04

- Added optional reputation resolver registration with ConditionSystem.

## 1.1.0 — 2026-10-04

- Added negative-to-positive default reputation tiers with stable IDs.
- Added partial or complete per-faction tier overrides.
- Added tier ID, rank, display-name, and full tier query APIs.
- Preserved 1.0 save data, commands, and arbitrary numeric checks.

## 1.0.1 — 2026-10-04

- Replaced `Object.hasOwn` with an RPG Maker MZ-compatible ownership check.

## 1.0.0 — 2026-10-04

- Initial release with configurable factions, global reputation, bounded
  values, threshold queries, save persistence, plugin commands, and script API.
