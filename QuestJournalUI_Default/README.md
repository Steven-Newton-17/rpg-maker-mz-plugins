# QuestJournal UI — Default

The original RPG Maker MZ-style menu for QuestJournal. It owns the menu command,
tabs, list, detail windows, navigation, and drawing only.

Install `QuestJournal.js` first and `QuestJournalUI_Default.js` immediately
below it. Enable only one QuestJournal UI theme at a time.

### 1.0.1

Quest details wrap objectives and scroll by mouse wheel, touch drag, and keyboard. Choose a quest, press OK or Right, then Up/Down or Page Up/Down; Cancel or Left returns to the quest list.
